# Assignment 1 — Web Engineering

Interactive single-page lab built with plain **HTML, CSS, and vanilla JavaScript** (no frameworks).

## Contents
| File | Purpose |
|---|---|
| `index.html` | Page layout: navigation, overview, and task sections |
| `style.css` | Styling (Inter typeface, responsive layout) |
| `script.js` | Dynamic DOM generation & student profile card builder logic |

## Tasks covered
- **Task 01** — Dynamic content generation via the DOM
- **Task 02** — Student profile card builder

## How to run
Open `index.html` in any modern browser (Chrome, Edge, Firefox). Works fully offline — the Inter font loaded from Google Fonts falls back cleanly to system fonts if unavailable.

# Web-Engineering
Web Engineering repository containing daily tasks, practice modules, and university assignments.

## Repository structure
Each task/assignment lives in its own numbered folder:

```
Web-Engineering/
├── README.md            ← you are here
├── LICENSE
└── assignment-1/        ← Assignment 1: interactive web lab
    ├── index.html
    ├── style.css
    └── script.js
```

Future work (e.g., `task1/`, `task2/`, `assignment-2/`) will be added alongside `assignment-1/`.

## How to work on a task
1. Add a new folder (e.g., `task1/`) for the task.
2. Put the task's files inside it.
3. Commit and push:
   ```bash
   git add <folder>
   git commit -m "Add task1: <short description>"
   git push
   ```
